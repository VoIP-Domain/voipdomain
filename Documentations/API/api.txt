  Versioning
--==========--

You can request calls to a specific resource version using "X-API-VERSION" HTTP header, or you can prefix the requested path with /vX/, where X is the desired API version.

  Search filters
--==============--

Search resources accept filters via the `q` and `fields` parameters; `fields` is a comma-separated list of desired fields. For example, you can search for extensions like: GET /api/extensions?q=Ernani&fields=ID,Name,Extension

  Response status codes
--=====================--

When a client sends a request, it needs clear feedback on success, client error, or server failure. HTTP status codes are a bunch of standardized codes that have various explanations in various scenarios. The server should always return the right status code.

The VoIP Domain API follows the standard HTTP response status codes, as follows:

  2xx (Success category)
--======================--

These status codes indicate that the requested action was received and successfully processed by the server.

- 200 OK: The standard HTTP response for successful GET, PUT, or POST requests.
- 201 Created: Returned whenever a new resource is created; the typical success response for POST.
- 204 No Content: Indicates that the request was processed successfully but returned no content. This should be a success DELETE response.

  3xx (Redirection category)
--==========================--

These status codes indicate that the response has no body but includes redirect or cache-related headers.

- 304 Not Modified: Indicates that the client has the response already in its cache. Therefore, the same data need not be transferred again.

  4xx (Client error category)
--===========================--

These status codes indicate that the client sent an invalid request.

- 400 Bad Request: Indicates that the request by the client was not processed, as the server could not understand what the client is asking for.
- 401 Unauthorized: Indicates that the client is not authorized; the client should repeat the request with valid credentials.
- 403 Forbidden: Indicates that the request is valid and the client is authenticated, but the client is not allowed to access the page or resource for any reason.
- 404 Not Found: Indicates that the requested resource is not available now.
- 410 Gone: Indicates that the requested resource is no longer available because it was intentionally removed.

  5xx (Server error category)
--===========================--

These status codes indicate that the server encountered an error and could not complete the request.

- 500 Internal Server Error: Indicates that the request is valid, but the server encountered an unexpected internal condition.
- 503 Service Unavailable: Indicates that the server is down or unavailable to receive and process the request, often because it is undergoing maintenance.
